## Planned sources

Chosen for coherence rather than volume: mixing packs is what makes free-asset
games look like asset flips, so architecture comes from a single pack and
creatures come from the same author where possible.

- **KayKit Dungeon Remastered** (CC0) — walls, floors, doors, props
- **KayKit character packs** (CC0) — creatures, same art style as the dungeon kit
- **Quaternius**, **Kenney** (CC0) — fill only, run through the unified material treatment
- **Poly Haven**, **ambientCG** (CC0) — textures and lighting
- **Mixamo** — animation
- **Freesound** (CC0), **Kenney audio**, **Sonniss GDC** — audio

## Adding an asset

1. Confirm the licence permits redistribution. If in doubt, do not use it.
2. Add a row above, with a link to the source.
3. Keep the original licence file alongside the asset if one is supplied.
